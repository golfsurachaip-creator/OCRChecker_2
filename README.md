# Scan Checker v2 (Android – Handheld + อ่านข้อความ)

กดปุ่มยิงที่เครื่อง handheld แล้วตรวจว่าตรงกับข้อความที่ตั้งไว้หรือไม่ แสดง **✓ ถูกต้อง** (เขียว) / **✗ ไม่ถูกต้อง** (แดง)
อ่านได้ทั้ง **บาร์โค้ด / QR** (จากหัวสแกนของเครื่อง) และ **ข้อความตัวพิมพ์** (OCR ด้วยกล้องของเครื่อง)

## การทำงาน
- **บาร์โค้ด/QR** – หัวสแกนของเครื่องอ่าน แล้วส่งค่าเข้าแอป (แบบคีย์บอร์ดหรือ Intent)
- **ข้อความ** – กดปุ่มยิงที่ตั้งไว้ (หรือปุ่ม "อ่านข้อความ" บนจอ) แอปจะอ่านภาพจากกล้องนาน 1.8 วินาที หยุดทันทีเมื่อเจอข้อความที่ถูกต้อง
- ถ้ากดยิงแล้วหัวสแกนอ่านบาร์โค้ดได้ด้วย แอปจะใช้ค่าบาร์โค้ดแทนผล OCR
- ผล OCR แสดงว่าข้อความไหน "พบ" / "ไม่พบ"; ถ้าภาพไม่มีตัวอักษรเลยจะขึ้น "อ่านข้อความไม่ได้" (สีส้ม ไม่นับเป็นผิด)
- ตัวนับ ถูก/ผิด, ประวัติพร้อมเวลา, ปุ่มไฟฉาย / เปิดไฟอัตโนมัติขณะอ่าน

> OCR อ่านได้เฉพาะตัวอักษรอังกฤษ ตัวเลข และสัญลักษณ์ (ยังไม่รองรับภาษาไทย)

## ตั้งค่าครั้งแรก (Keyence BT-A500)
1. เปิดแอป → อนุญาตใช้กล้อง
2. **ตั้งค่า** → ใส่ข้อความที่ถูกต้อง (1 บรรทัด = 1 ข้อความ)
3. **ตั้งปุ่มยิงสำหรับอ่านข้อความ…** → กดปุ่มยิงที่เครื่อง 1 ครั้ง → บันทึก
   - ถ้ากดแล้วหน้าต่างไม่รับปุ่ม แปลว่าระบบสแกนของเครื่องจองปุ่มยิงไว้ ให้เข้า Settings ของเครื่อง → ส่วนตั้งค่าปุ่ม (Key assignment) แล้วกำหนดปุ่มยิงด้านใดด้านหนึ่งให้ส่งเป็นปุ่มทั่วไป (เช่น F1) จากนั้นตั้งปุ่มนั้นในแอป
   - แนะนำ: ปุ่มยิงหนึ่งปุ่มสำหรับบาร์โค้ด (หัวสแกน) และอีกปุ่มสำหรับอ่านข้อความ (แอป)
4. รับบาร์โค้ด: Settings → Scanner → Data output → เปิด Keystroke, Delivery type = KeyEvent (หรือใช้ Intent ตามตารางด้านล่าง)

## Broadcast Intent (ไม่บังคับ)
| ยี่ห้อ | Action | Extra |
|---|---|---|
| Keyence BT-A500 | `com.fgl.scancheck.SCAN` (Settings → Scanner → Data output → Intent, Broadcast) | `data` |
| Zebra (DataWedge) | `com.fgl.scancheck.SCAN` | `com.symbol.datawedge.data_string` |
| Urovo | `android.intent.ACTION_DECODE_DATA` | `barcode_string` |
| Newland | `nlscan.action.SCANNER_RESULT` | `SCAN_BARCODE1` |
| iData / Kaicom | `android.intent.action.SCANRESULT` | `value` |
